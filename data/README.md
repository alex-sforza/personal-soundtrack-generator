# Data layer

`music.json` — будущая база музыкальных референсов. Каждая композиция будет иметь жанровые, сюжетные и эмоциональные параметры для алгоритма подбора.

`character-options.json` — варианты для интерактивной анкеты персонажа и его сюжетной дуги. Справочник адаптирован под мир Lily-Dale и расширен общими ролевыми вариантами.

## Music scoring fields

- `drama` — драматическая нагрузка
- `romance` — романтика / притяжение
- `danger` — опасность
- `mystery` — мистика / тайна
- `hope` — надежда
- `chaos` — хаос
- `loneliness` — одиночество
- `nostalgia` — ностальгия
- `conflict` — конфликт
- `energy` — энергия

Все оценки: 0–10.
